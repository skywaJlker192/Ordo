# Ordo

**Ordo наводит порядок в файлах сам.** Ты один раз описываешь правила «когда → если → то», а программа сидит в трее и раскладывает новые файлы из «Загрузок» (или любой другой папки) по местам. Плюс маленькие автоматизации на горячих клавишах, по расписанию и по буферу обмена, которые собираются мышью из блоков, как в Scratch.

- Лёгкая: Python и PyQt5, никаких нейросетей и тяжёлых фоновых процессов.
- Безопасная: ничего не удаляется без следа, каждое действие пишется в журнал и откатывается одной кнопкой.
- Рассчитана на Windows (горячие клавиши, автозапуск и трей). Ядро и консоль работают и на Linux/macOS.

## Установка

**Вариант 1: готовый .exe.** Скачай `Ordo-windows.zip` из раздела [Releases](../../releases) (или из вкладки Actions → последняя сборка → Artifacts), распакуй куда угодно и запусти `Ordo.exe`. Установка не нужна.

**Вариант 2: из исходников.** Нужен Python 3.9 или новее.

```bash
git clone https://github.com/skywaJlker192/Ordo.git
cd Ordo
pip install -e ".[gui]"
ordo gui
```

## Первый запуск за 2 минуты

1. Запусти Ordo. Откроется окно, а в трее (у часов) появится значок.
2. Правила для «Загрузок» уже готовы (картинки, видео, документы, архивы, установщики и т.д.), остаётся включить слежение: переключатель «Слежение» слева внизу.
3. Скачай любой файл. Через пару секунд он уедет в нужную папку внутри «Загрузок», а трей покажет уведомление.
4. Что-то разложилось не туда? Вкладка **Журнал** → выбери пакет → **Отменить выбранный** (или **Отменить последний**).

Хочешь сначала посмотреть, что будет, ничего не трогая: на главной нажми **Разобрать сейчас**. Откроется предпросмотр со списком «что куда переедет», и только кнопка «Применить» запустит перенос.

## Как пользоваться

Слева вкладки (быстро переключаются по `Ctrl+1` … `Ctrl+6`):

| Вкладка | Что там |
|---|---|
| **Главная** | Включено ли слежение, цифры, график активности за 14 дней, самые частые правила, последние действия. |
| **Правила** | Что и куда раскладывать. Карточки по порядку, включение переключателем, дублирование, импорт и экспорт. |
| **Сценарии** | Свои автоматизации из блоков-пазлов. |
| **Журнал** | Все операции пакетами. Любой пакет раскрывается до отдельных файлов и откатывается. |
| **Папки** | За какими папками следить и сколько секунд ждать, пока файл «осядет» (чтобы не трогать недокачанное). |
| **Настройки** | Автозапуск с Windows, поведение трея, уведомления, радиальное меню, корзина Ordo. |

**Трей.** Крестик окна не закрывает Ordo, а сворачивает его в трей, чтобы слежение продолжалось. Значок зелёный, когда слежение включено, серый, когда на паузе. Правый клик: открыть, пауза, разобрать сейчас, радиальное меню, **Выход** (закрывает совсем).

**Откат.** Каждый запуск разбора и каждая пачка файлов от слежения записываются как «пакет». Откат возвращает файлы на прежние места и убирает пустые папки, которые создал Ordo. Если на старом месте уже лежит другой файл, Ordo его не затрёт, а пропустит и скажет об этом.

## Правила

Правило читается как предложение: **ЕСЛИ** файл такой-то, **ТО** сделай так-то. Файл проверяется правилами сверху вниз, срабатывает первое подходящее (если у правила не снята галочка «остановиться после него»).

**Создать правило:** вкладка Правила → «Новое правило». Всё заполняется формой, внизу окна сразу видно, как Ordo прочитает правило словами.

Что можно проверять:

- **Тип файла.** Определяется по содержимому, а не по имени: `photo.txt`, внутри которого PNG, будет понят как картинка. Типы: картинка, видео, аудио, документ, архив, установщик, код, другое.
- Имя, расширение, настоящее расширение, размер (`500KB`, `10MB`, `1.5GB`), возраст в днях, полный путь, «расширение не совпадает с содержимым».
- Сравнения: равно, содержит, начинается с, заканчивается на, подходит под регулярку, больше, меньше, «одно из» и обратные.

Что можно сделать: переместить, скопировать, переименовать по шаблону, отправить в корзину Ordo (не системную: оттуда файл возвращается откатом, пока корзина не очищена).

В путях и шаблонах работают подстановки (в редакторе вставляются кликом): `{name}` `{stem}` `{ext}` `{real_ext}` `{type}` `{year}` `{month}` `{day}` `{size_mb}`. Например, `Скриншоты/{year}-{month}` разложит скриншоты по месяцам. Относительный путь считается от разбираемой папки, абсолютный (`~/Documents/Важное`) работает как есть.

Если имя занято, Ordo не перезаписывает файл, а создаёт `file (1).png`.

**Обмен правилами.** Кнопки «Экспорт» и «Импорт» сохраняют и загружают правила в JSON, набор можно отправить другу. Битые правила при импорте отбрасываются с объяснением, что с ними не так.

### Что есть из коробки

Исправить расширение, Скриншоты (по месяцам), Чеки и договоры, Изображения (по годам), Видео, Музыка, Документы, Архивы, Установщики, Код и данные. Правило «Старые установщики в корзину» выключено по умолчанию: включи его сам, если хочешь.

### Правило в JSON

Для тех, кто любит править руками (`config.json`):

```json
{
  "name": "Скриншоты",
  "match": "all",
  "stop": true,
  "conditions": [
    { "field": "type", "op": "equals", "value": "image" },
    { "field": "name", "op": "startswith", "value": ["screenshot", "снимок экрана"] }
  ],
  "actions": [
    { "do": "move", "to": "Скриншоты/{year}-{month}" }
  ]
}
```

Поля: `name`, `stem`, `ext`, `real_ext`, `type`, `path`, `size`, `age_days`, `mismatch`. Операции: `equals`, `not_equals`, `in`, `not_in`, `contains`, `not_contains`, `startswith`, `endswith`, `regex`, `gt`, `gte`, `lt`, `lte`. Действия: `move`/`copy` (`to`), `rename` (`template`), `trash`.

## Сценарии

Сценарий отвечает на вопрос «когда → что сделать» и собирается из блоков. Верхний блок («Когда…») запускает сценарий, ниже идут блоки действий, которые выполняются по порядку. Если какой-то шаг упал, остальные не выполняются, и Ordo покажет, что именно сломалось.

**Как собрать:** вкладка Сценарии → «Новый сценарий». Слева палитра: клик по блоку добавляет его, или перетащи на поле. Порядок блоков меняется перетаскиванием за точки слева, убираются они крестиком. Кнопка **Проверить** выполняет сценарий прямо сейчас. Не хочется собирать с нуля: кнопка **Шаблоны** добавит готовый.

**Когда (триггеры):**

| Блок | Что делает |
|---|---|
| Нажато сочетание клавиш | Работает в любой программе. Поле ловит реальное нажатие: кликни в него и нажми, например, `Ctrl+Alt+L`. Нужна хотя бы одна из Ctrl, Alt, Shift, Win. |
| Наступило время | Каждые N минут, каждый день в заданное время или по будням. Если компьютер был выключен в нужное время, пропущенное не догоняется. |
| Скопирован текст | Срабатывает, когда в буфер попал текст: любой, содержащий слово или подходящий под регулярку. |
| Запущен Ordo | Один раз при старте. |

**Делать (действия):**

| Блок | Что делает |
|---|---|
| Разобрать папку | Применяет правила к выбранной папке (или ко всем под присмотром). Попадает в журнал и откатывается. |
| Открыть | Запускает папку, файл, программу или ссылку (`http`, `https`, `mailto`). Опасные схемы вроде `ms-msdt:` или `javascript:` Ordo не открывает. |
| Показать уведомление | Сообщение в окне, а если окно свёрнуто, то из трея. |
| Скопировать в буфер | Кладёт текст в буфер. В тексте работают `{clipboard}`, `{date}`, `{time}`. |
| Обработать буфер | Убрать пробелы по краям, склеить в одну строку, сделать строчными или ПРОПИСНЫМИ, убрать `utm_` и прочий трекинг из ссылок. |

**Готовые шаблоны:**

- **Чистая ссылка** (`Ctrl+Alt+L`): скопировал ссылку, нажал, и из неё пропали `utm_` и трекинг.
- **Текст в одну строку** (`Ctrl+Alt+J`): склеивает скопированный многострочный текст.
- **Ссылка из буфера в браузер** (`Ctrl+Alt+B`): открывает ссылку, которая лежит в буфере.
- **Утренняя уборка**: по будням в 09:00 разбирает все папки.
- **Уборка каждый час**: проверяет папки раз в час, даже если слежение выключено.
- **Открыть Загрузки** (`Ctrl+Alt+D`): быстро открывает папку «Загрузки».

**Безопасность импорта.** Сценарии из чужого файла всегда добавляются **выключенными**. Если они что-то открывают, Ordo сначала покажет список целей и спросит подтверждения. Проверь и включи сам.

Если сочетание уже занято другой программой, Ordo покажет сообщение «Не удалось занять …»: выбери другое.

## Радиальное меню

Нажми `Ctrl+Alt+Space` в любой программе: у курсора плавно раскроется круг с пунктами. Выбери мышью или цифрой 1–8, `Esc` или клик мимо закрывает.

Пункты по умолчанию: разобрать, откатить, пауза или включение слежения, открыть «Загрузки», открыть Ordo. Можно добавить любые свои сценарии (до 8 пунктов). Сочетание клавиш и набор пунктов меняются в **Настройки → Радиальное меню**, там же кнопка «Попробовать». Сочетание, которое уже занято сценарием, Ordo сохранить не даст.

## Консоль

Всё то же самое можно делать без окна, например в скриптах:

```bash
ordo init           # создать ~/.ordo/config.json из пресета для «Загрузок»
ordo preview        # показать, что будет сделано (файлы не трогает)
ordo run            # применить правила (спросит подтверждение)
ordo watch          # следить за папками и разбирать новые файлы сразу
ordo undo           # откатить последний пакет
ordo history        # журнал операций
ordo stats          # статистика
ordo empty-trash --older-than 30   # удалить навсегда старое из корзины Ordo
ordo gui            # открыть окно (--minimized: сразу в трей)
```

`ordo run --folder D:\Хлам` разберёт любую папку по тем же правилам. `--config путь\config.json` берёт другой конфиг.

## Где лежат данные

Всё в папке `~/.ordo` (на Windows `C:\Users\Имя\.ordo`), открыть её можно кнопкой в Настройках:

- `config.json` — правила, папки, сценарии, настройки радиального меню. Можно править руками: перед сохранением Ordo проверяет файл и не даст записать битый.
- `config.json.bak` — копия предыдущей версии.
- журнал операций (SQLite) и `trash/` — корзина Ordo.

Другое место для данных: переменная окружения `ORDO_HOME`.

Ordo ничего не отправляет в интернет и не собирает данные.

## Если что-то не работает

- **Файл не разобрался.** Проверь, что слежение включено и папка есть на вкладке «Папки». Файлы, которые ещё качаются (`.crdownload`, `.part`), Ordo намеренно пропускает и ждёт, пока они «осядут».
- **Файл ушёл не туда.** Журнал → «Отменить выбранный». Потом на вкладке «Правила» поправь порядок: побеждает первое подходящее правило.
- **Горячая клавиша не срабатывает.** Скорее всего, её уже занимает другая программа (Ordo об этом предупредит). Выбери другое сочетание. Часть сочетаний с Win зарезервирована самой Windows.
- **Антивирус ругается на .exe.** Сборки PyInstaller без подписи иногда вызывают ложные срабатывания. Можно запустить из исходников (вариант 2) или собрать .exe самому.
- **Закрыл окно, а Ordo всё ещё работает.** Так и задумано, он в трее. Полностью: правый клик по значку → Выход.

## Сборка .exe и разработка

**Собрать .exe на Windows** (нужен Python 3.9+ в PATH):

```bat
packaging\build.bat
```

Результат: `dist\Ordo\Ordo.exe` (папку можно запаковать в zip и раздать).

**Автосборка на GitHub.** Workflow `.github/workflows/build.yml` прогоняет тесты и собирает `Ordo-windows.zip` на Windows. Вручную: Actions → «Сборка Ordo.exe» → Run workflow. Чтобы выложить релиз:

```bash
git tag v0.1.0
git push --tags
```

**Тесты.**

```bash
pip install -e ".[dev]"
pytest
```

Устройство: `ordo/` — ядро без интерфейса (правила, движок, журнал, сценарии, горячие клавиши), `ordo/gui/` — окно на PyQt5, `packaging/` — сборка, `tests/` — тесты.

> Горячие клавиши, автозапуск и трей написаны под Windows. На Linux они проверены тестами с заглушками WinAPI, а сборка .exe проверена только в части «бандл собирается и запускается» (на Linux).
