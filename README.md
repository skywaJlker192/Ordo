# Ordo

Порядок в файлах. Описываешь правила в формате **когда → если → то**, а Ordo сам разбирает папки: «Загрузки», рабочий стол, что угодно. Ничего не удаляет без следа: каждая операция пишется в журнал, и любой пакет можно откатить.

> Этап 2: ядро, консоль и окно приложения с треем. Дальше: визуальный редактор блоков, триггеры, радиальное меню, дубликаты.

## Быстрый старт

```bash
pip install -e .
ordo init           # создаст ~/.ordo/config.json из готового пресета для «Загрузок»
ordo preview        # покажет, что будет сделано (файлы не трогает)
ordo run            # применит правила (спросит подтверждение)
ordo watch          # будет следить за папкой и разбирать новые файлы сразу
ordo undo           # откатит последний пакет операций
```

Другие команды: `ordo history`, `ordo stats`, `ordo empty-trash --older-than 30`.
`ordo run --folder D:\Хлам` разберёт любую другую папку по тем же правилам.

## Окно приложения

```bash
pip install -e ".[gui]"     # добавит PyQt5
ordo gui                    # откроет окно (или команда ordo-gui)
ordo gui --minimized        # сразу в трей
```

- **Главная:** состояние слежения, цифры, график активности за 14 дней, рейтинг правил, последние действия.
- **Правила:** карточки по порядку, переключатель, порядок стрелками, дублирование, импорт и экспорт в JSON.
- **Редактор правил формой**, без JSON: условия и действия, подстановки `{year}` кликом, внизу описание правила словами.
- **Предпросмотр** перед разбором: что и куда переедет, с кнопкой «Применить».
- **Сценарии:** собираются из блоков-пазлов как в Scratch (перетаскивание мышью). Триггеры: горячая клавиша, расписание, буфер обмена, запуск Ordo. Действия: разобрать папку, открыть, уведомить, скопировать в буфер, обработать буфер (убрать utm, склеить в строку…). Есть 6 готовых шаблонов, импорт и экспорт; импортированное приходит выключенным.
- **Журнал:** пакеты операций раскрываются до файлов, любой пакет откатывается кнопкой.
- **Папки, настройки:** добавить или убрать папку, время «осаживания» файла, автозапуск с Windows, корзина Ordo.
- **Трей:** значок с индикатором (зелёный = слежение включено), меню, уведомления о разобранных файлах, закрытие окна сворачивает в трей.
- Вторая копия не запускается: просто показывает уже открытое окно.

## Что умеет ядро

- **Тип по содержимому, а не по имени.** `photo.txt`, внутри которого PNG, будет понят как картинка (и расширение можно исправить автоматически).
- **Правила с цепочками.** `stop: false` позволяет сначала переименовать, потом отсортировать.
- **Умные шаблоны путей и имён:** `Скриншоты/{year}-{month}`, `{stem}.{real_ext}`.
- **Не затирает файлы.** Имя занято → `file (1).png`. Откат тоже ничего не перезаписывает.
- **Предпросмотр, журнал, откат, статистика.**
- **Наблюдатель.** Недокачанные файлы (`.crdownload`, `.part`) игнорирует и ждёт, пока файл «осядет».
- Лёгкий: никаких нейросетей, только `watchdog` и стандартная библиотека.

## Формат правил

```json
{
  "name": "Скриншоты",
  "match": "all",
  "stop": true,
  "conditions": [
    { "field": "type", "op": "equals", "value": "image" },
    { "field": "name", "op": "startswith", "value": ["screenshot", "снимок экрана"] }
  ],
  "actions": [
    { "do": "move", "to": "Скриншоты/{year}-{month}" }
  ]
}
```

| | Варианты |
|---|---|
| **Поля** | `name`, `stem`, `ext`, `real_ext`, `type`, `path`, `size`, `age_days`, `mismatch` |
| **Типы** | `image`, `video`, `audio`, `document`, `archive`, `installer`, `code`, `other` |
| **Операции** | `equals`, `not_equals`, `in`, `not_in`, `contains`, `not_contains`, `startswith`, `endswith`, `regex`, `gt`, `gte`, `lt`, `lte` |
| **Действия** | `move` (`to`), `copy` (`to`), `rename` (`template`), `trash` |
| **Плейсхолдеры** | `{name} {stem} {ext} {real_ext} {type} {year} {month} {day} {size_mb}` |

- Размеры можно писать как `500KB`, `10MB`, `1.5GB`.
- Относительный путь в `to` считается от разбираемой папки, абсолютный (`~/Documents/Важное`) работает как есть.
- `trash` отправляет файл в корзину Ordo (`~/.ordo/trash`), откат возможен.
- Правила проверяются сверху вниз, срабатывает первое подходящее (если не `stop: false`).
